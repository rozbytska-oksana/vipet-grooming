# Заявки через Telegram на HostPro

Форма зберігає обраний клієнтом Telegram, Viber, Instagram або Facebook.
Адміністратор отримує заявку в Telegram та відповідає клієнтові через його
обраний канал. Дата й час візиту погоджуються окремо.

## Передумови

Потрібні PHP 8.1+, cURL, iconv, HTTPS та дозвіл на вихідні HTTPS-запити
до api.telegram.org у тарифі HostPro. Сайт генерується статично, обробник
public/api/booking.php виконується PHP-сервером. Nuxt dev самостійно PHP не виконує.

## Бот і отримувач

1. У Telegram відкрийте офіційний @BotFather та виконайте `/newbot`.
   Створіть окремого бота для заявок салону.
2. Скопіюйте `.env.example` у `.env`, якщо локального `.env` ще немає.
   Якщо він існує, додайте потрібні змінні до нього.
3. Запишіть отриманий токен у приватний `.env` як `VIPET_TELEGRAM_BOT_TOKEN`.
   Токен зберігайте приватно, як пароль. Публічні змінні Nuxt призначені лише
   для прапорця доступності форми й адреси обробника.
4. Власниця відкриває створеного бота у своєму Telegram та натискає Start.
5. У корені проєкту виконайте команду нижче. Скрипт показує ID чатів, які
   написали боту. Для отримувача оберіть ID особистого чату власниці.

```sh
node --env-file=.env scripts/telegram-chat-id.mjs
```

Інструкції Telegram наведені в [офіційному посібнику](https://core.telegram.org/bots/tutorial#obtain-your-bot-token).

## Приватний файл на HostPro

Скопіюйте deployment/vipet-booking-config.example.php під назвою
vipet-booking-config.php у батьківську папку кореня сайту. Наприклад, для
`/home/account/public_html` це буде `/home/account/vipet-booking-config.php`.
Фактичний корінь сайту перевірте в панелі HostPro.

Заповніть у файлі `bot_token`, `chat_id`, `allowed_origin` та встановіть
`enabled` у `true`. Origin — точна адреса сайту з протоколом HTTPS без
шляху та фінального слеша. Отримувач має бути тим самим чатом, який натиснув Start.
Надайте файлу доступ лише для облікового запису, від якого працює PHP.

Якщо конфігурація зберігається в іншій приватній папці, задайте її абсолютний
шлях через серверну змінну `VIPET_BOOKING_CONFIG_PATH`. Обробник перевіряє,
що конфігурація розташована поза DOCUMENT_ROOT.

Поруч із конфігурацією PHP створить vipet-booking-state.json із доступом 0600.
Папка має дозволяти запис користувачу PHP. Файл містить keyed-хеші, часові мітки,
номери заявок та стани доставки. Записи мають строк 24 години для захисту від
повторів, ліміт спроб за адресою клієнта становить 5 за 10 хвилин. Використовується
REMOTE_ADDR. Якщо сайт працює через проксі, налаштування реальної IP-адреси
потрібно узгодити з HostPro перед запуском.

## Збірка та завантаження

У приватному `.env` змініть `NUXT_PUBLIC_BOOKING_ENABLED` на `true` після
налаштування обробника. Значення `NUXT_PUBLIC_BOOKING_ENDPOINT=api/booking.php`
є відносним до app.baseURL.

```sh
npm run generate
```

`pregenerate` синхронізує booking-catalog.json із breeds, services та pricingRules.
Так само каталог оновлюється перед dev та build. На сервер перенесіть вміст
`.output/public`, включно з `api/booking.php` і `api/booking-catalog.json`.
Приватну конфігурацію розмістіть окремо, як описано вище. Збережіть чинні правила
хостингу й перевірте, що POST до PHP-файлу виконує PHP замість HTML fallback.

До активації доступна локальна перевірка полів. Після активації браузер передає
JSON через POST на сервер. Секрети читає PHP. Успіх повертається лише після
відповіді Telegram `ok=true` з `message_id`.

## Перевірка доставки

Виконайте одну погоджену з власницею тестову заявку. Перевірте її отримання,
канал зв’язку, контакт, ім’я улюбленця, послугу та параметри калькулятора.
Перевірте помилки полів, блокування кнопки на час запиту й відсутність повтору
після повторного запиту з тим самим requestId. За невизначеної мережевої помилки
повтор цього ID блокується до перевірки доставки, щоб уникнути дублювання.

Після успішної заявки поля залишаються видимими. Зміна даних дозволяє оформити
нову заявку. Результати надсилання й контакти клієнтів не записуються в аналітику.

Локальне виконання PHP та реальна доставка потребують перевірки на HostPro.
На момент підготовки PHP на комп’ютері відсутній, токен і chat_id ще не задані.

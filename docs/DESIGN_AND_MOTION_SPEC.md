# 00. Глобальна дизайн-система

## 0.1. Концепція

Напрям дизайну:

**Luxury Editorial × Premium Pet Care × Immersive Experience**

Сайт має викликати асоціації з преміальним beauty-брендом, але зберігати теплоту й індивідуальність грумінг-салону.

Візуальні характеристики:

- Графітовий фон.
- Золоті металеві акценти.
- Контрастні молочні секції.
- Великі фотографії тварин.
- Елегантна serif-типографіка.
- Тонкі декоративні лінії.
- М'які світлові ефекти.
- Достатня кількість вільного простору.
- Плавні анімації при скролі.
- Декоративні лапки та елементи, пов'язані з грумінгом.

Не використовувати надмірно яскраві кольори, стандартні сині кнопки або шаблонний дизайн салонів.

## 0.2. Кольорова палітра

| `--color-graphite-deep` | `#232325` | Hero та темні секції |
| `--color-graphite-dark` | `#1C1C1E` | Найглибші акценти |

| `--color-cream` | `#F7F1EA` | Світлі секції |
| `--color-gold` | `#C6A667` | Основне золото |
| `--color-gold-light` | `#E8C98A` | Світлі золоті акценти |
| `--color-gold-dark` | `#A77B38` | Глибина золотих елементів |
| `--color-silver` | `#C9C9CD` | Срібні елементи |
| `--color-text-light` | `#F5F1EA` | Текст на темному фоні |

Для золотих кнопок дозволяється градієнт:

```css

  135deg,
  #e8c98a 0%,
  #c6a667 45%,
  #f2d79e 70%,
  #b88945 100%

```

Не застосовувати один і той самий відтінок графіту до всіх секцій.

Глибина кольору має змінюватися залежно від композиції.

## 0.3. Типографіка

Основні шрифти:

- **Cormorant Garamond** — великі українські заголовки, елегантний текст, акцентні фрази.
- **Bodoni Moda** — вибрані англомовні декоративні заголовки.
- **Manrope** — основний текст, форми, навігація, прайс.

Для українського тексту перевіряти підтримку кирилиці.

Рекомендована шкала для desktop:

| Елемент | Розмір |
|---|---|
| Hero brand title | 100–136px |
| Hero slogan | 42–56px |
| Section heading | 54–72px |
| Card title | 25–32px |
| Body text | 16–18px |
| Small labels | 12–14px |
| Numeric statistics | 58–76px |
| Button text | 18–21px |

Розміри мають адаптуватися через `clamp()`.

## 0.4. Контейнер і відступи

Рекомендації:

- Максимальна ширина контенту: 1360–1440px.
- Горизонтальні відступи desktop: 48–80px.
- Вертикальні відступи секцій: 100–140px.
- Hero: орієнтовно 820–950px заввишки на великих екранах.
- Відстань між заголовком і контентом: 40–64px.
- Відстань між картками: 20–32px.

Не стискати секції лише для того, щоб вони відповідали пропорціям загального зображення-макета.

Кожна секція має виглядати як самостійна композиція преміального сайту.

## 0.5. Глобальні правила анімацій

Використовувати:

- GSAP.
- ScrollTrigger.
- CSS transitions.
- CSS transforms.
- Embla Carousel для відповідних галерей.

Анімації появи повинні запускатися **під час фактичного прокручування сторінки до секції**.

Заборонено запускати всі scroll reveal анімації одночасно під час завантаження сторінки.

Стандартні параметри:

| Тип | Duration | Easing |
|---|---|---|
| Heading reveal | 0.8–1.1s | `power3.out` |
| Paragraph reveal | 0.6–0.8s | `power2.out` |
| Card reveal | 0.65–0.9s | `power3.out` |
| Image reveal | 0.9–1.2s | `power3.out` |
| Hover | 0.25–0.35s | CSS ease |
| Count Up | 1.5–2s | `power2.out` |
| Carousel transition | 0.5–0.7s | smooth easing |
| Gold shimmer | 0.6–0.8s | CSS ease |

Стандартний ScrollTrigger:

```js
{
  start: 'top 80%',
  once: true
}
```

Це рекомендоване значення, яке можна змінювати для окремих секцій.

Для елементів усередині секції використовувати окремі тригери, якщо вони з'являються в різні моменти прокручування.

# 01. HEADER + HERO BANNER

## 1.1. Загальна композиція

Hero — головний елемент усього сайту.

Він повинен бути:

- Великим.
- Кінематографічним.
- Багатошаровим.
- Преміальним.
- Насиченим дрібними, але делікатними деталями.

Фон — глибокий графіт із затемненням по краях.

Не використовувати плоский чорний або простий однотонний сірий фон.

### Header

Header розташовується поверх Hero.

Desktop:

**Ліворуч:**
- Логотип V.I.Pet.
- Маленький підпис Grooming Salon.

**По центру:**
- Головна.
- Послуги.
- Прайс.
- Наші роботи.
- Грумер.
- Відгуки.
- FAQ.
- Контакти.

**Праворуч:**
- Instagram.
- Telegram.
- Viber.
- Золота кнопка «Записати улюбленця».

Активний пункт меню має тонку золоту лінію під текстом.

Кнопка — без стрілки.

Header може бути sticky, але під час скролу його фон має плавно ставати більш непрозорим графітовим.

## 1.2. Ліва частина Hero

Орієнтовна ширина: 38–42%.

Вертикальна структура:

1. Маленький напис `GROOMING SALON`.
2. Великий напис `V.I.Pet`.
3. Декоративні маленькі золоті лапки в композиції логотипа.
4. Тонка золота горизонтальна лінія під назвою.
5. Слоган:

   **«Кожен улюбленець особливий»**

6. Короткий текст:

   «Професійний грумінг собак і котів у Житомирі».

7. Три мікропереваги:
   - Довіра.
   - Турбота.
   - Професіоналізм.

8. Велика золота кнопка:

   **«Записати улюбленця»**.

9. Декоративний індикатор прокручування вниз.

Слоган має бути виконаний великим елегантним курсивом золотого кольору.

Мікропереваги розділити тонкими вертикальними золотими лініями.

## 1.3. Права частина Hero

Орієнтовно 58–62% ширини.

Головна композиція:

- Великий світлий пухнастий собака з елегантним золотим бантом.
- Поруч сірий кіт із виразними очима.
- Тварини розташовані на темній оксамитовій тканині.
- Позаду — велике тонке золоте світлове кільце.
- На задньому плані — приглушений інтер'єр грумінг-салону.

Повернути декоративні деталі зі старого макета:

**1. Золота світлова дуга**

Розташовується за тваринами.

Дуга не повинна перекривати мордочки.

**2. Grooming accessories**

Праворуч або в нижній частині композиції:

- Професійні ножиці.
- Щітка або гребінець.
- Флакон косметики.

Предмети мають виглядати реалістично та преміально.

**3. Оксамитова тканина**

Темна драпірована тканина з акуратними складками.

Можна використати графітовий відтінок із майже чорними тінями.

**4. Декоративна лапка на задньому плані**

Велика напівпрозора лапка з делікатним золотим сяйвом.

**5. Світлові стрічки**

Тонкі золоті хвилі:

- У лівій частині Hero.
- Позаду тварин.
- У нижній частині композиції.

**6. Маленькі золоті частинки**

Кілька світлових точок у фоновому шарі.

Не створювати велику кількість частинок або постійні важкі ефекти.

## 1.4. Анімація Hero

Hero має складатися з кількох послідовних анімацій.

### Етап 1 — початкове завантаження

**0.0–0.4s**

З'являється фон Hero.

Логотип і навігація плавно проявляються:

- `opacity: 0 → 1`
- `translateY: -12px → 0`

### Етап 2 — бренд

**0.3–1.1s**

Поява напису `GROOMING SALON`.

Потім великий `V.I.Pet` з reveal-ефектом знизу вгору.

Букви не повинні хаотично рухатися.

Анімація має бути стриманою та дорогою.

### Етап 3 — слоган

**0.8–1.5s**

Слоган «Кожен улюбленець особливий» плавно з'являється.

Золота лінія під логотипом промальовується зліва направо.

### Етап 4 — тварини

**0.4–1.7s**

Композиція собаки та кота:

- Плавна поява.
- `scale: 1.04 → 1`.
- Невелике зміщення знизу вгору.

Тварини не повинні різко збільшуватися або рухатися в різні боки.

### Етап 5 — золоте кільце

**0.8–2.0s**

Поступове проявлення світлової дуги.

Рекомендовано використовувати SVG або підготовлений декоративний шар.

Якщо кільце реалізоване через SVG:

- Анімувати `stroke-dashoffset`.
- Не застосовувати надмірний blur.

### Етап 6 — декоративні деталі

**1.2–2.2s**

Плавно з'являються:

- Ножиці.
- Щітка.
- Косметика.
- Фонова лапка.
- Маленькі золоті акценти.

### Етап 7 — CTA

**1.4–2.2s**

З'являються:

- Мікропереваги.
- Кнопка запису.
- Індикатор скролу.

## 1.5. Scroll-анімація Hero

Під час прокручування Hero:

- Тварини можуть зміщуватися на 10–25px.
- Фонове золоте кільце — зміщуватися з меншою швидкістю.
- Декоративні стрічки — мати легкий паралакс.
- Текстова композиція — плавно втрачати прозорість ближче до завершення Hero.

Використовувати тільки невеликий паралакс.

Не змінювати розміри та позицію основного контенту настільки, щоб він виходив за межі контейнера.

На мобільних складний паралакс вимикати.

## 1.6. Hover-ефекти

### Золота кнопка

При наведенні:

- Зліва направо проходить світлий золотий відблиск.
- Кнопка трохи світлішає.
- Текст не рухається.
- Жодних стрілок.

### Іконки соціальних мереж

- Плавна зміна кольору на золото.
- Незначне збільшення до `scale(1.06)`.

# 02. PHILOSOPHY / НАШ ПІДХІД

## 2.1. Структура

Світлий молочний фон.

Десктопна горизонтальна композиція.

**Ліва частина: 30–35%.**

Великий editorial-заголовок:

«Наш підхід —
більше, ніж стрижка»

Під заголовком — декоративний золотий мазок або витончена лінія.

**Права частина: 65–70%.**

Чотири переваги:

1. Професійна турбота та любов.
2. Безпечна косметика преміумкласу.
3. Індивідуальний підхід.
4. Комфорт і спокій під час процедур.

Кожна перевага:

- Мінімалістична контурна іконка.
- Текст.
- Достатній простір навколо.

Між елементами можна використати тонкі вертикальні розділювачі.

## 2.2. Анімації

### Поява секції

Коли секція потрапляє у viewport:

1. Заголовок з'являється знизу.
2. Золота декоративна лінія промальовується.
3. Іконки з'являються послідовно.
4. Підписи проявляються з невеликою затримкою.

### Параметри

- Heading: 0.9s.
- Line reveal: 0.7s.
- Icons: 0.6s.
- Stagger: 0.12s.

### Hover

На десктопі при наведенні на перевагу:

- Іконка трохи піднімається.
- Контур стає золотим.
- Невелике масштабування.

Без великих фонів і карток навколо кожної переваги.

Плавна поява знизу.

Коли ряд карток входить у viewport:

- `opacity: 0 → 1`.
- `translateY: 55px → 0`.
- `scale: 0.97 → 1`.

Послідовність:

- Перша картка.
- Друга через 0.1s.
- Третя через 0.1s.
- Четверта через 0.1s.
- П'ята через 0.1s.

Важливо: анімація починається лише тоді, коли користувач доходить до секції.

### Hover картки

При наведенні:

1. Картка піднімається на 6–8px.
2. Золота рамка стає трохи виразнішою.
3. Фото збільшується до `scale(1.04)`.
4. Золота плашка отримує легкий відблиск.

Не збільшувати всю картку настільки, щоб вона перекривала сусідні.

### Click

Натискання на картку може:

- Прокрутити до калькулятора.

**Права: 65–70%.**

Великий інтерактивний блок порівняння фотографій.

Зображення мають бути однакового співвідношення сторін.

На фото:

- Ліва частина — «До».
- Права частина — «Після».
- Вертикальний повзунок посередині.
- Круглий золотистий або світлий контрол із двома стрілками.

Знизу можна додати маленькі індикатори кількості прикладів.

## 4.2. Анімація входу

Коли секція потрапляє у viewport:

1. З'являється заголовок.
2. Промальовується декоративна лінія.
3. Блок фотографій плавно проявляється.
4. Після завершення reveal може виконатися одноразова демонстрація повзунка.

### Демонстрація повзунка

Повзунок:

- Починає з центрального положення.
- Плавно зміщується трохи праворуч.
- Повертається назад у центр.

# 05. MEET THE GROOMER / ГРУМЕР

- Великий.

### Фонова лапка

- Золотий світловий контур.
- Досить велика.
- Розташована за портретом.
- Частково перекривається силуетом.
- Не повинна відволікати від обличчя.

Для реалізації використовувати SVG або легку CSS-композицію.

Можна додати кілька маленьких золотих точок.

## 5.3. Права частина — контент

Маленький золотий overline:

**«ГРУМЕР»**

Не використовувати старий заголовок «Про грумера».

Основний заголовок:

**«Людина, якій довіряють найцінніше»**

Під ним - текст про власницю.

Останнє речення повинно завершуватися фразою:

**«…де кожен улюбленець — ВІП.»**

Приклад структури тексту:

«Для мене грумінг - це не просто красива стрижка, а турбота про здоров'я, комфорт і емоції вашого улюбленця. Я прагну створити простір, де кожен улюбленець особливий.»

Фінальний текст узгоджується з клієнткою.

Останню фразу можна стилізувати золотим курсивом.

Під текстом — декоративний підпис власниці, якщо для цього є погоджений матеріал.

## 5.4. Статистика

Під текстом розмістити три показники:

- Років досвіду.
- Професійних навчань.
- Щасливих улюбленців.

### Важлива деталь

**Повернути декоративне обрамлення цифр зі старого макета.**

Кожен числовий показник має:

- Велику золоту цифру.
- Декоративні лаврові гілочки або витончене золоте обрамлення з боків.
- Підпис знизу.
- Простір між показниками.

Між статистичними групами — тонкі вертикальні золоті розділювачі.

Не використовувати звичайні прямокутні картки.

Обрамлення має виглядати як частина luxury editorial дизайну.

## 5.5. Анімація портрета

Коли секція з'являється:

1. Фонова лапка поступово проявляється.
2. Портрет піднімається знизу на 35–50px.
3. Плавно з'являється заголовок.
4. Проявляється основний текст.
5. Анімується декоративний підпис.
6. Починають працювати числові лічильники, коли сам блок статистики потрапляє у viewport.

### Портрет

- `opacity: 0 → 1`.
- `translateY: 45px → 0`.
- `scale: 1.025 → 1`.
- Duration: 1.1s.

### Фонова лапка

- Плавне проявлення контуру.
- Duration: 1.2–1.5s.
- Без постійного пульсування.

## 5.6. Count Up Animation

Обов'язково реалізувати раніше затверджену анімацію.

Числа збільшуються:

`0 → targetValue`

Тривалість:

**1.5–2 секунди.**

Використовувати:

- GSAP.
- ScrollTrigger.
- `power2.out`.

Умови:

- Запуск лише при появі статистики у viewport.
- Один раз.
- Без повторення при скролі назад.
- Плавне заокруглення до цілих чисел.
- Символ `+` відображається після завершення, якщо передбачений.
- Підтримка reduced motion.

Не використовувати вигадані цифри в production. Дані повинні надходити з конфігурації контенту.

### Обрамлення цифр

Лаврові гілочки можуть проявитися:

- Через opacity.
- Із невеликим scale.
- Після завершення або під час фінальної фази Count Up.

Гілочки не повинні постійно рухатися.

# 15. Архітектура анімацій

Не писати весь GSAP-код в `index.vue`.

Рекомендована структура:

```text
app/
├── components/
│   ├── sections/
│   │   ├── HeroSection.vue
│   │   ├── PhilosophySection.vue
│   │   ├── ServicesSection.vue
│   │   ├── BeforeAfterSection.vue
│   │   ├── GroomerSection.vue
│   │   ├── CertificatesSection.vue
│   │   ├── PetGallerySection.vue
│   │   ├── PricingSection.vue
│   │   ├── WhyChooseUsSection.vue
│   │   ├── TestimonialsSection.vue
│   │   ├── FaqSection.vue
│   │   └── BookingSection.vue
│   │
│   ├── ui/
│   │   ├── GoldButton.vue
│   │   ├── SectionHeading.vue
│   │   ├── GoldDecoration.vue
│   │   ├── AnimatedCounter.vue
│   │   └── BeforeAfterSlider.vue
│   │
│   └── layout/
│       ├── SiteHeader.vue
│       └── SiteFooter.vue
│
├── composables/
│   ├── useScrollReveal.ts
│   ├── useCountUp.ts
│   ├── useReducedMotion.ts
│   └── useGsapContext.ts
│
├── data/
│   ├── services.ts
│   ├── pricing.ts
│   ├── testimonials.ts
│   └── faq.ts
│
└── pages/
    └── index.vue
```

Адаптувати до фактичної структури Nuxt 4 проєкту.

## Вимоги до GSAP

1. Підключати GSAP лише на клієнті.
2. Не звертатися до `window` або `document` під час SSR.
3. Використовувати `onMounted` для ініціалізації.
4. Ізолювати анімації всередині компонентів.
5. Використовувати `gsap.context()` або еквівалентний підхід.
6. Очищувати анімації та ScrollTrigger при unmount.
7. Не створювати дублікати trigger при повторному монтуванні.
8. Підтримувати `prefers-reduced-motion`.
9. Не приховувати контент назавжди, якщо JavaScript або GSAP не завантажилися.
10. Використовувати `transform` та `opacity`, де можливо.

## Вимоги до ScrollTrigger

Scroll reveal має бути прив'язаний до фактичного входження елемента у viewport.

Не використовувати один загальний trigger для всієї сторінки.

Не запускати всі анімації одразу при завантаженні.

Не повторювати одноразові reveal-анімації при поверненні назад.

Для довгих секцій дозволяється створювати окремі тригери для:

- Заголовка.
- Контентної сітки.
- Фотографій.
- Інтерактивних елементів.

## Reduced Motion

Якщо користувач увімкнув зменшення руху:

- Вимкнути паралакс.
- Вимкнути декоративні складні анімації.
- Одразу показувати фінальні цифри.
- Не виконувати автоматичний рух Before/After.
- Залишити доступну функціональність усіх компонентів.

# 16. Responsive Design

Поточне ТЗ фіксує desktop-композицію.

Фінальний мобільний дизайн буде деталізований окремо.

До цього моменту необхідно забезпечити базову адаптивність без горизонтального переповнення.

Поведінка:

### Desktop ≥ 1280px

Повні великі композиції.

Максимальна кількість декоративних деталей.

### Tablet 768–1279px

Менше горизонтальних елементів.

Перенесення карток у додаткові рядки за потреби.

Зменшення декоративних ефектів.

### Mobile < 768px

Вертикальна композиція.

Менша кількість декоративних шарів.

Відсутність складного паралаксу.

Зручні touch-контроли.

Усі п'ять послуг доступні без прихованої кнопки.

Не видаляти секції на мобільних пристроях.

# 17. Performance Requirements

Основні вимоги:

- Nuxt 4 із SSR або SSG відповідно до архітектури.
- Responsive images.
- AVIF/WebP.
- Lazy loading поза першим екраном.
- Оптимізований Hero.
- Мінімізація важких filter і blur-анімацій.
- Відсутність нескінченних анімацій без необхідності.
- Обмеження одночасно активних ScrollTrigger.
- Коректне очищення ресурсів.

Цільові метрики:

- LCP ≤ 2.5s.
- CLS ≤ 0.1.
- INP ≤ 200ms.
- Lighthouse Performance ≥ 90 на мобільних.
- Lighthouse Accessibility ≥ 95.

Це цілі для перевірки, а не гарантії.

Не жертвувати основною функціональністю та доступністю заради декоративних ефектів.

# 19. Обов'язкові критерії приймання

Завдання не вважається виконаним, якщо:

- Hero перетворився на звичайну двоколонкову секцію без деталей.
- Відсутні золота дуга, фонова лапка або grooming-аксесуари.
- Замість графіту використано суцільний чорний фон.
- Зникли золоті декоративні лінії.
- У секції послуг відсутня будь-яка з п'яти карток.
- Є кнопка «Показати всі».
- Портрет грумера показаний у звичайній прямокутній картці.
- Відсутня велика золота лапка за портретом.
- Статистика не має декоративного обрамлення.
- Count Up не запускається при входженні у viewport.
- Анімації всіх секцій запускаються одночасно.
- FAQ відсутній на desktop або mobile.
- Калькулятор показує вигадані ціни.
- Відгуки або досягнення вигадані.
- Форма показує успіх без фактичного надсилання.
- Секції надмірно стиснуті.
- Контент має горизонтальний overflow.
- Анімації заважають доступності.

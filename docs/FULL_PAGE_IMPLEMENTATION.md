## Реалізовано

`index.vue` явно імпортує секції в узгодженому порядку: Hero, Philosophy, Services,
Groomer, Certificates, BeforeAfter, Gallery, Pricing, WhyChooseUs, Testimonials,
FAQ, Booking; Contacts у SiteFooter. Один h1. H2 мають стабільні IDs і tabindex
для програмного focus. Preview лишається noindex; фіктивних JSON-LD/canonical немає.

- Philosophy: кремова editorial секція, три цінності без гарантій/статистики.
- Services: п’ять демонстраційних напрямів із фотографіями, stagger reveal, image
  hover zoom і gold border. Підтверджений каталог поки порожній. Demo cards не є
  тарифами чи підтвердженим переліком послуг; це прямо пояснено на сторінці.
- Groomer: ілюстрація процесу без обличчя, місце для реального імені й історії,
  декоративний flourish. Статистика відображається лише з реальними записами.
- Certificates: стан без документів; після наповнення `salon.ts` працює Embla
  carousel з посиланнями на full-size та native dialog. Фальшивих дипломів немає.
- Before/After: явно позначена вигадана AI-пара, native range 0–100, touch/keyboard,
  перемикання на два зображення поруч; без JS обидва фото видимі. Геометрія кадру
  зарезервована. Автоматичну демонстрацію повзунка не додано, вона optional.
- Gallery: Embla swipe, кнопки й лічильник позицій, native image preview, desktop
  GSAP parallax самих фото без pin або перехоплення прокручування. Без JS native
  horizontal overflow, links відкривають фото напряму.
- Pricing: pet/breed/service/extras, фільтрація сумісності, атомарне оновлення range,
  чиста функція `calculatePrice`. Без каталогу й тарифів — стан уточнення, не 0 грн.
- Why V.I.Pet: три brand principles, без вигаданого обладнання чи кваліфікацій.
- Testimonials: компонування для реальних цитат; зараз чесний стан без відгуків.
- FAQ: native details/summary, однаково desktop/mobile; preview-відповіді описують
  поточну форму й невідомість тарифів, а не непідтверджені практики салону.
- Booking: усі запитані поля, Telegram/Viber/email, перенесення selection з pricing.
  Дані клієнта/коментар не змінюються при prefill. Зміна виду очищає несумісні pet
  fields, зміна каналу очищає формат контакту. Надсилання вимкнене, endpoint відсутній.
  Використано `role=form` контейнер замість активного native form, щоб Enter/no-JS
  не могли відправити персональні дані у URL. При delivery інтеграції замінити на
  native form + server validation, privacy copy та реальні pending/error/success.
- Footer: підтверджені назва/місто; контакти, години та socials тільки після наповнення.

## Motion та lifecycle

`useReducedMotion` слухає зміни media query; SSR починається зі статичного стану.
`useScrollReveal` — IntersectionObserver + Web Animations, 700ms, 16px, одноразово,
без приховування контенту до JS. При reduced motion активні animations скасовуються.
`useCountUp` — rAF 1800ms, once, screen-reader фінальне число, width зарезервована.
`useGalleryMotion` — scoped GSAP matchMedia ≥1200px, cleanup і async unmount guard.
Embla duration 0 при reduced motion, без autoplay, own events прибираються;
Vue wrapper сам знищує carousel instance. Діалог повертає фокус, підтримує Escape.

## Перевірки

- Додані сім Vitest cases для synthetic pricing fixtures: missing data, exact breed,
  additive/included/quote extras, unknown IDs, duplicate rules/extras, invalid ranges.
  Fixtures живуть лише в tests і не імпортуються в UI.
- П’ять прямих assertions через Node 24 TypeScript stripping пройшли: additive price,
  missing tariff, duplicate extras, incompatible pet, incomplete selection.
- На першій спробі Vitest і build зависли через macOS `compressed,dataless` files:
  `_breakpoints.scss`, `node_modules/fdir/package.json` та інші вивантажені файли.
  Агент зупинив лише власні завислі процеси. Користувача попросили завантажити папку.
- Browser backend відновився (Opera ID 5), але localhost:3000 повертає
  ERR_CONNECTION_REFUSED: dev server зараз не працює. Native Finder automation
  недоступна через відсутній Computer Use permission. Це не успішний browser QA.
- Фінальні результати build/format/typecheck/browser дописати після відновлення
  доступу до файлів. Попередні результати Header/Hero не підтверджують нові секції.

## Виправлення миготіння scroll reveal

Початковий стан below-fold елементів готується при mounted через paused WAAPI
(fill both), а observer лише запускає анімацію за48px до входження. Елементи,
які вже у viewport під час setup, залишаються видимими й не анімуються повторно.
Фокус на контролі одразу завершує reveal; cleanup/reduced-motion скасовують
анімації, повертаючи видимий базовий CSS. Без JS контент видимий.
Модельна перевірка prepared/paused/play/cleanup PASS; Prettier PASS.
Browser scrolling QA недоступна.

## Золотий перелив рамки послуг

підсвітка без обертання. Немає нескінченної фонової анімації.

## Темний футер і повернення вгору

Футер у charcoal #252527, світле оригінальне лого, молочні тексти й золоті акценти. Окремий BackToTop: темна кругла кнопка 48px з SVG-стрілкою справа знизу, з safe-area відступами. Показ після max(480px, 85% висоти екрана); passive scroll + rAF, resize, cleanup. Native scrollTo smooth, reduced motion instant; фокус переходить на main до приховування кнопки. Без JS кнопки немає, основна навігація залишається доступною. Кнопка прихована під час відкритого native dialog. Нових залежностей немає.

Перевірки футера: Prettier, vue-tsc, nuxt generate в ізольованій копії — PASS. У статичному HTML перевірено dark surface, світле лого, tel:+380635908730, графік, Maps URL і відсутність текстового посилання «На початок». Візуальна перевірка та прокрутка у браузері ще не виконані.

Правка футера: заголовки контактів/графіка/навігації золоті; Google Maps відкривається натисканням на саму адресу, окремий текстовий лінк прибрано.

Контакти футера: звичайний font-weight:400 і без підкреслення (також при hover), телефон у тому ж відтінку, що адреса; focus-visible залишається. Instagram наданий власницею й підключений через business.instagramUrl, без tracking-параметра igsh.

Контактні рядки футера (адреса, телефон, соцмережі) уніфіковані: Manrope 400, 1rem/1.6, молочний колір. Підпис профілю — «Наш Instagram». Золоті serif-заголовки збережені.

Контактна група футера об’єднана з брендовою: один заголовок «Завітайте до V.I.Pet», короткий опис, адреса-посилання Google Maps, телефон і контактні іконки. Окрема колонка лого/слогана прибрана, залишились три desktop-колонки. Instagram і телефон — круглі золоті SVG-іконки з доступними назвами; Telegram/Viber не показуються без підтверджених URL. Попередній принцип клікабельної адреси без окремого Maps-лінка збережено.

Уточнення власниці: брендова група з оригінальним світлим лого та слоганом «Догляд з любов’ю до кожної деталі» відновлена як перша окрема колонка. Об’єднаний контактний блок збережено другою, графік і навігація — третьою та четвертою. Tablet 2×2, mobile послідовний список колонок.

Контактний футер: адресу зроблено неклікабельним текстом, текстовий телефон прибрано. Порядок іконок: локація Google Maps, Instagram, телефон; номер збережений у tel URL і доступній назві кнопки дзвінка.

Короткі золоті лінії під заголовками; mobile горизонтальні розділювачі груп, desktop вертикальні. Іконки м’яко підсвічуються на hover, reduced motion вимикає transitions. Mobile-навігація у дві колонки для компактності. Браузерна перевірка не виконана.

Вертикальні розділювачі між колонками футера прибрані за уточненням власниці.

Загальний фон: root surface змінено з чорного #0b0c0e на графітовий #29292b через --color-graphite. HTML і body використовують однаковий surface, включно з фоном поза контентом. Явні світлі/темні фони секцій збережені.

## FAQ — 8 листопада 2026

Десять наданих власницею запитань замінюють preview FAQ. Дані окремі: answer — абзаци, optional points — списки для періодичності візитів/складу послуг. UI рендерить через текстові вузли, без v-html. Весь контент у SSR і native details для desktop/mobile, існуюча плавна BaseDisclosure-анімація та reduced motion збережені. Виправлено друкарські помилки, розриви рядків та пошкоджені entities, без нових бізнес-тверджень. Якщо надалі додаватиметься FAQ JSON-LD, відповідь повинна включати і answer, і points.

FAQ: локальна адаптивна композиція — заголовок із золотою хвилею та ледь помітною SVG-лапкою ліворуч, список праворуч на desktop; на mobile одна колонка. Запитання мають тонку золоту рамку, молочну поверхню й м’яке виділення відкритого стану. Keyboard focus — золотий outline із зовнішнім підсвічуванням; forced-colors використовує Highlight. Native details, плавне розгортання та reduced motion збережено.

Уточнення FAQ: заголовок центрований із хвилею за зразком відгуків; фонову лапку та окремі світлі картки прибрано. Запитання на спільному молочному фоні з тонкими золотими розділювачами; золотий focus-visible збережений. Картки відгуків отримали conic-gradient перелив по рамці (2.4 с, один оберт при hover/focus-within), як у послуг. Псевдоелемент не перехоплює кліки й не змінює розміри; reduced motion залишає статичну рамку.

Картки відгуків: золотий перелив і hover-підсвічування прибрані, оскільки сама картка не клікабельна. Статична золота рамка та масштабування активного елемента каруселі збережені.

FAQ: зовнішні вертикальні відступи уніфіковано з відгуками — clamp(2rem, 3vw, 3rem); додатковий padding заголовка прибрано. Горизонтальні відступи — спільний BaseContainer.

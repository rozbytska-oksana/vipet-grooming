# Другий блок — «Наш підхід»

Реалізація 2026-11-04 за розділом02 DESIGN_AND_MOTION_SPEC.md.

- Самостійна semantic section із h2, tabindex для якірної навігації й чотирма
  цінностями; зайві overline та проміжний statement прибрані.
- Desktop від1200px: заголовок приблизно1/3, переваги2/3; від768px переваги
  в один ряд, mobile — два стовпці. Milk background, dark text, gold-ink icons,
  тонкі розділювачі, декоративний SVG штрих під заголовком.
- Заголовок/іконки/підписи використовують існуючий useScrollReveal: окремі
  IntersectionObserver targets, once,700ms, stagger120ms, підписи ще+120ms.
  Лінія промальовується окремим observer900ms із затримкою200ms.
- Reduced motion та його зміна під час роботи скасовують animations, cleanup
  відключає observers; SSR/no-JS контент видимий. Hover лише fine pointer:
  підняття іконки4px/scale1.04, без clickable cards.
- Текст «Безпечна косметика преміумкласу» не використаний без бізнес-підтвердження;
  тимчасово «Делікатний догляд». Інші пункти — цінності бренду, без статистики
  чи сертифікацій. Реальні засоби й формулювання узгодити перед production.

конфлікту з dev server. Vue-tsc: лише існуючі TS18047 у PricingSection.vue:172,
нових помилок у другому блоці немає. ESLint відсутній, lint не запускався.
Opera localhost:3000/#philosophy: desktop1380px screenshot перевірений,
console errors/warnings порожні; DOM при375px підтвердив дві колонки167.5px
і відсутність page overflow. Mobile screenshot transport повертав застаріле
зображення Hero, тому mobile visual QA не зараховано. Browser reduced-motion,
no-JS та холодний CLS не перевірені; не заявляються виконаними.

## Компактність за відгуком користувача

Вертикальні padding зменшено з56–104px до28–48px, заголовок — з36–60px
до30–44px. Відстань між заголовком і цінностями на mobile24px замість32px.
Це пряме уточнення користувача замінює початкові просторі відступи секції.

## Плавніші reveal та повна видимість заголовка

Reveal другого блоку1400ms з opacity0 і ease-out; stagger240ms, підпис+240ms.
useScrollReveal отримав необов’язкові параметри, default timing інших секцій
збережений. Fill backwards утримує початковий стан під час stagger delay.
Header wrapper більше не трансформується: reveal застосований до h2.
Line observer стежить за всім header (h2+SVG), threshold1 і запас24px знизу.
Промальовування1500ms починається лише після повного входження header у viewport.
Reduced-motion і cleanup збережені.

## Невелике прискорення за уточненням користувача

Reveal1100ms, stagger180ms, підпис+180ms. Лінія1200ms із затримкою180ms;
повна видимість heading як умова запуску збережена.

## Повторне невелике прискорення

Reveal900ms, stagger140ms, підпис+140ms; лінія1000ms із затримкою140ms.
Умова повної видимості header, easing і reduced-motion збережені.
Перевірено Prettier; зміна стосується лише таймінгів цієї секції.

# Розрахунок вартості — реалізація

Орієнтир: наданий користувачем screenshot із компактним текстом зліва та
рамкою калькулятора справа. Власний semantic section, графітова палітра,
золотий radio toggle собака/кіт, native selects породи й послуги, результат
за золотим розділювачем. Mobile — один стовпець; medium — три controls і
результат нижче; x-large — вступ та панель поруч, чотири колонки в панелі.

Початковий стан: собака, породу не вибрано; показано запрошення обрати породу,
без вигаданої ціни за замовчуванням. У dropdown послуг лише наявні для обраної
породи тарифи; зміна виду/породи/послуги очищує залежні параметри. Для метисів
і купання собак є вагова категорія; для великих порід у комплексі — шерсть.
Для невідомого/непідтвердженого поєднання — «Вартість уточнюється».
Ціна показується точним значенням або діапазоном у грн із бази в копійках.

Знижки та доплати лише у native details із примітками, без арифметичного
застосування — явне рішення користувача. Додаткові примітки з наступних
повідомлень треба додати до цього переліку. Немає нових бізнес-обіцянок.
Тривалість для великих порід показується лише для комплексу за джерелом.

CTA переносить породу, вид, послугу, вагову категорію та довжину шерсті у
існуючу preview-форму. Перенесені умови показуються текстом; при зміні виду
в booking вони очищуються. Це не відправлення і не підтвердження запису.

ServicesSection відокремлена від списку послуг калькулятора: її п’ять
редакційних категорій, поточні AVIF/WebP та діапазони збережені. Це запобігає
підміні всіх карток fallback-зображенням після наповнення services.ts.

Доступність: fieldset/legend, native radio keyboard behavior, labels,
focus-visible, aria-live polite для результату. CSS fade320ms має reserved
min-height; reduced-motion вимикає transitions. SSR показує текст і controls.
Немає browser APIs у server render і нових залежностей.

Перевірки: 20/20 Vitest, включно6 тестів підтверджених тарифів, породних
відмінностей, відсутніх ваги/шерсті, мейн-куна та джерел кожного rule.
Vue-tsc PASS (попередню проблему null range усунено через discriminated union).
Prettier PASS. Isolated nuxt generate PASS3.89s; SSR controls/heading/notes
присутні, старий placeholder про відсутні тарифи прибрано.
Browser automation недоступна: responsive visual, keyboard runtime,
client navigation та CLS ще не перевірені. Не заявляти їх виконаними.

## Дворядне компонування і ковзний toggle

На medium/x-large поля мають окрему grid із двома колонками: вид і порода
у першому рядку, послуга у другому (повна ширина). Якщо потрібні вага або
шерсть, другий рядок ділиться навпіл. На mobile поля йдуть одним стовпцем
для читабельності. Результат на desktop стоїть праворуч від обох рядків.

Золотий thumb — один pseudo-element, переміщується transform420ms. Градієнт
BaseButton винесено без зміни кольорів у спільний --button-gold-flow, обидва
використовують background-size200%. Native radio, focus-visible і reduced-motion
збережені; forced-colors має статичний системний outline. Селекти мають
appearance none й SVG-chevron за16px від правого краю, з резервом44px під нього.
Prettier та isolated generate PASS; browser visual QA недоступна.

## Плавне розгортання

BaseDisclosure зберігає native details/summary і без JS. Після hydration
useExpandMotion анімує висоту й opacity контенту420ms при відкритті та закритті.
Такий самий компонент використано для FAQ. Додаткові поля калькулятора мають
Vue Transition з JS hooks вимірювання висоти; grid розподіляє їм другу половину
рядка. Reduced-motion завершує анімації одразу, onBeforeUnmount скасовує їх.
Під час закриття контент inert, summary зберігає фокус і native keyboard activation.
Prettier/generate перевірені; browser interaction QA недоступна.

## Світлова хвиля та промальовування лінії

useStrokeReveal готує paused WAAPI для SVG pathLength1 і запускає1200ms
із затримкою250ms, коли intro повністю у viewport із запасом24px знизу.
Запуск один раз, cancellation при unmount/reduced-motion. Без JS SVG видимий.
Під лівою частиною секції — статичний inline SVG зі світловими кривими,
локальним золотим сяйвом та контуром лапки4.5% opacity. Декор aria-hidden,
pointer-events none, у межах overflow clip; зображення не завантажуються.
Prettier і isolated generate PASS; runtime visual QA недоступна.

# Відгуки — 7 листопада 2026

Блок одразу після GroomerSection із вкладеними сертифікатами. Молочний фон, світлі картки із золотою рамкою, Embla loop/center/skipSnaps, swipe, кнопки та крапки. Картки у повній ширині сторінкового контейнера, більші за сертифікати у третині секції. Mobile 88%, tablet дві, desktop три. Scale .96 → 1 за 600ms, reduced motion без анімації. Без autoplay. Без JS горизонтальний scroll.

Дані окремо в app/data/testimonials.ts. Google Maps URL надала власниця. Рейтинг, автори, аватари, дати та тексти не вигадані. До отримання скриншотів масив був порожній: Google Maps не повернув тексти через web tool чи публічний HTML, очікуємо скопійовані оригінали від користувачки. До цього показуємо спокійне посилання на справжню сторінку Google Maps, без фальшивих карток. Нема автоматичного оновлення/запитів Google з клієнта, API-ключів чи review schema.

Потрібно: імена авторів, точні тексти, оцінки й за можливості прямі посилання. Після отримання перевірити реальну довжину карток у браузері. Браузерна перевірка ще не виконана.

## Реальні відгуки зі скриншотів

Додано 16 текстових відгуків, усі з оцінкою 5 на наданих зображеннях. Два профілі з оцінкою без тексту не перетворені на текстові картки. Імена й мова збережені, відповіді власниці та сервісні поля Google не входять у цитату. Шість видимих обірваних уривків позначено excerpt; відносні дати не конвертовані у вигадані календарні. Індивідуальних URL немає — загальне посилання веде на надану сторінку салону. Фото авторів/песиків зі скриншотів не вирізались. Довгі цитати розгортаються кнопкою; без JS весь текст видимий. Автоматичного оновлення немає.

Перевірки: Prettier змінених файлів, vue-tsc і nuxt generate в ізольованій копії — PASS. У HTML перевірено наявність текстів і порядок Groomer → Testimonials → Philosophy. Візуальна браузерна перевірка не виконана.

Правки компонування: відступи секції 2–3rem, заголовок та SVG-лінія як у ServicesSection, менші внутрішні поля карток і проміжки керування. Крапки — рухоме вікно максимум п’яти реальних snap-позицій в один ряд на всіх екранах; активна завжди присутня. Позначка «уривок» прибрана з UI, поле excerpt та фактичні межі цитат збережені в даних. Кнопка розгортання — «Читати далі».

Активна картка збільшується до scale(1.06), сусідні .96, без зміни layout; вертикальний запас із від’ємними margin зберігає компактні відступи. Reduced motion вимикає обидва масштаби. Посилання: «Усі відгуки в Google Maps».
